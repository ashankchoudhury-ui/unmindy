# UNMINDY — App Features

## Core Mechanism
- Scroll-interrupt: Detects when user enters mindless scrolling mode
- Lock-in commitment: Locks user into a productive task for a set duration
- Context-aware redirects: Suggests tasks matching the distraction source

## Feature Ideas (Ranked)

### Must-Build (MVP)
1. **Escape Hatch design** — "Done early" button (partial credit) + "Emergency exit" (2-tap, 10s delay, logged as bail)
2. **Progressive commitment levels** — Level 1: gentle redirect → Level 2: puzzle lock → Level 3: app lockdown → Level 4: full focus
3. **Haptic + visual feedback** — Vibration on lock, breathing-rhythm animation, progress ring

### Should-Build (V1)
4. **Content-aware task suggestions** — Instagram → creative task, TikTok → physical task, Twitter → learning task
5. **Focus Buddy system** — Share lock-in sessions with friends, encouragement messages delivered post-session
6. **Streak counter** — Visual streak display with safe-area insets, dark mode (#000 bg, #0d9488 teal accent)

### Could-Build (V2)
7. **Context-aware redirects** — Auto-suggest tasks based on what app was opened
8. **Web dashboard for parents/teachers** — Daily focus time, app usage trends (no raw data)
9. **Social sharing** — "I just completed a 20-min lock-in" share card with streak

### Won't-Build (Future)
10. **Full lockdown mode** — Phone only allows calls + timer (Android only)
11. **Voice-to-task** — Speak a task, app creates lock-in session for it

## Monetization
- **Tier 1 (Free)**: 3 lock-ins per day, basic redirect suggestions
- **Tier 2 ($3/month)**: Unlimited + social features + detailed analytics
- **Tier 3 ($10/month)**: Full lockdown + web dashboard + priority support
